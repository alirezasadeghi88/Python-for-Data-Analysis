## Purpose

This repository serves as an advanced learning workspace and open-source reference for mastering data manipulation, analysis, and cleaning using Python. The primary goal is to build a robust foundation for **Data Science**, **Machine Learning**, and **Data-Driven Backend Systems**.

---

## Main Topics Covered

- Python Advanced Basics & Built-in Data Structures
- High-Performance Numerical Computing with **NumPy**
- Data Manipulation, Grouping, and Indexing with **Pandas**
- Data Cleaning, Missing Data Handling, and String Operations
- Data Wrangling, Joining, Merging, and Reshaping
- Data Visualization with **Matplotlib** & **Seaborn**
- Efficient Data Loading, Storage, and File Formats (CSV, JSON, HDF5, Databases)
- Basic Statistical Concepts and Introduction to Modeling (Scikit-Learn)
